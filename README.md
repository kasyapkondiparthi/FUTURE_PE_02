# AI Content Marketing Using UGC Ads

## Project Overview

This project demonstrates how Prompt Engineering and Artificial Intelligence can be used to create authentic, high-converting User Generated Content (UGC) advertisements for a real business.

The goal was to build a reusable prompt framework capable of generating marketing assets that can be used by brands, agencies, and content creators across multiple social media platforms.

---

## Business Chosen

### QuizMaster Pro

QuizMaster Pro is an Online Quiz & Assessment Platform designed for Coaching Centers and Educational Institutions.

The platform helps institutes:

* Conduct online quizzes
* Generate instant results
* Automate grading
* Track student performance
* Reduce faculty workload
* Improve assessment efficiency

---

Create a complete AI-powered UGC Ad Content Pack that can generate:
